ATtiny85 Explorer v0.6.0 - Clean Portable Release
=================================================

Double-click ATtiny85_Explorer.exe to start the program.

Keep these three items together:

  ATtiny85_Explorer.exe
  app folder
  runtime folder

The app is fully portable. It does not install anything, display an extraction
window, require Python, or require a build step. Settings, logs, projects, and
backups are stored under %APPDATA%\ATtiny85 Explorer.

Supported target: Windows 7 SP1 through Windows 11, 32-bit or 64-bit.
